# Neevii Ink — Downloads

Official download releases for **Neevii Ink**.

| Platform | Download | Requirements |
|---|---|---|
| Windows 10/11 x64 | [Latest offline setup (.exe)](../../releases/latest) | 64-bit Windows 10 or 11; WebView2 included |
| Linux x86-64 (Ubuntu 24.04+) | [Latest offline installer (.run)](../../releases/latest) | Ubuntu 24.04+ x86-64, glibc 2.39; AppImage embedded |

Windows builds are unsigned and may show a publisher prompt. Use the release's `SHA256SUMS.txt` to verify either installer.

The Linux `.run` installer embeds the AppImage — no separate `.AppImage` or `.deb` download needed.

This repository contains public download metadata and release assets. Application source is private. See [the website](https://www.neevii.com/get-ink) for release notes and installation requirements.
